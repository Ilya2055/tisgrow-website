# Tisgrow Media Folder

Use this folder for small website media files.

## Folders

- `assistants` - photos or portraits for AI consultant cards.
- `videos` - video thumbnails or very small demo video files.
- `logos` - Tisgrow logos and partner/client logos.
- `backgrounds` - website background images.
- `portfolio` - portfolio images or example project screenshots.

## Important

Keep the website fast.

Use local files here for:

- small images
- assistant card photos
- video thumbnails
- small portfolio screenshots

Do not store very large videos directly in the project.

For large videos, use:

- YouTube
- Vimeo
- Google Drive
- another video hosting service

Then add the video link or embed to the website.

## File Naming

Use simple file names without spaces.

Good examples:

- `sofia-beauty.jpg`
- `makar-architecture.jpg`
- `tisgrow-dental.jpg`
- `beauty-demo-thumbnail.jpg`

Avoid:

- `Sofia Beauty Photo Final Version.jpg`
- `video demo 1.mov`
